# Dual Allegiance in Practice: Trust in Traditional Leaders vs. Elected Local Government in Ghana

A survey-data analysis and interactive app testing the "dual allegiance" model of Ghanaian local governance, the idea that citizens relate to two parallel systems of local authority: elected District Assembly councils and traditional leaders (chieftaincy).

The research question comes from my own published work on decentralisation and traditional authority in Ghana. This project tests it quantitatively on nationally representative survey data, combining classical statistical inference with machine learning.

**Data:** Afrobarometer Round 9 (2022), Ghana, n = 2,369 respondents across 16 regions.

---

## Key findings

- **Trust is low for both institutions and statistically indistinguishable.** Mean trust (0–3 scale) is 0.92 for elected local government councils and 0.95 for traditional leaders (paired t = 1.85, p = 0.064, n = 2,318).
- **The urban–rural gap is smaller than classical accounts expect.** Rural respondents trust traditional leaders slightly more (1.01 vs. 0.91 urban), but the difference is modest.
- **Councillor performance is widely disapproved.** 60.6% of Ghanaians disapprove or strongly disapprove of their local government councillor's performance. Perceived corruption is similar for both groups (1.52 local government vs. 1.47 traditional leaders).
- **Stated trust and behaviour diverge.** Among respondents who trust traditional leaders "a lot", more contacted a local government councillor (40.3%) than a traditional leader (37.0%) in the past year.
- **Demographics barely predict who leans traditional.** In a logistic regression, women (OR 0.76, p = 0.014) and more educated respondents (OR 0.93 per level, p = 0.023) are slightly less likely to trust traditional leaders more than local government. Overall predictive power is weak (ROC-AUC 0.57 for logistic regression, 0.58 for Random Forest; 5-fold CV 0.579 ± 0.035), which is itself a substantive finding: allegiance is not well explained by demographics alone.

## Methods

- **Data preparation:** Ghana subset of the Afrobarometer Round 9 merged file; ordinal trust, corruption and performance items recoded to 0–3 scales; demographic controls (urban/rural, age, gender, education, lived poverty).
- **Inference:** paired t-test on institutional trust; group comparisons by urban/rural and region; logistic regression with odds ratios and 95% confidence intervals.
- **Machine learning:** Random Forest classifier as a non-parametric robustness check, evaluated on a held-out test set and with 5-fold stratified cross-validation (ROC-AUC).

## Run it yourself

**Notebook**

```bash
pip install -r requirements.txt
cd analysis
jupyter notebook ghana_dual_allegiance_analysis.ipynb
```

**Streamlit app**

```bash
cd streamlit_app
pip install -r requirements.txt
streamlit run app.py
```

The app has four tabs: a filterable dashboard of the core charts, a live prediction tool (logistic regression and Random Forest, trained in-session), and a data explorer for the raw and recoded data. It can be deployed to Streamlit Community Cloud with `streamlit_app/app.py` as the main file.
